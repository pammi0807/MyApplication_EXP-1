# MyApplication_EXP-1
Aim

To develop a simple Android application that displays the message “Hello World” on the screen using Android Studio.

Algorithm

1. Start Android Studio.

2. Create a new Android project.

3. Select Empty Activity template.

4. Open the file activity_main.xml.

5. Add a TextView component.

6. Set the text property to “Hello World!”.

7. Open MainActivity.java.

8. Set the layout using setContentView(R.layout.activity_main).

9. Run the application using an emulator or Android device.

10. The output displays Hello World on the screen.
